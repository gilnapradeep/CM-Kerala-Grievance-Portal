# 07 – User Guide

## 1. Public visitor
1. Open the portal home page.
2. Read About Us, How It Works, Departments and FAQ.
3. Use Track Grievance with a valid reference number to view public status information.
4. Use Contact Us to submit an enquiry.

## 2. Citizen
1. Select Register and provide the requested details.
2. Log in using the registered username and password.
3. Open Submit a Grievance.
4. Select district and category.
5. Enter a concise subject and a factual description.
6. Optionally attach permitted supporting documents.
7. Submit and save the generated reference number.
8. Open My Dashboard to view submitted grievances.
9. Use Track Grievance to check public progress.
10. After a grievance is resolved, submit feedback if the feature is enabled.

## 3. CMO administrator
1. Sign in using the CMO demo account.
2. Open CMO Dashboard.
3. Review grievance information and dashboard counts.
4. Request AI analysis when appropriate.
5. Review AI suggestions and approve/reject them; do not treat unreviewed suggestions as official decisions.
6. Assign the grievance to a department/officer if assignment is enabled.
7. Review officer action reports.
8. Approve or reject reports with remarks.

## 4. Department officer
1. Sign in using the officer demo account.
2. Open Officer Dashboard.
3. Review assigned grievances and their details.
4. Update status with meaningful remarks.
5. Submit investigation details, action taken and resolution details to the CMO.

## 5. Status definitions
| Status | Meaning |
|---|---|
| Submitted | The grievance has been received |
| Under Review | The grievance is being examined |
| In Progress | Action is being taken |
| Resolved | A resolution has been recorded |
| Reopened | Further attention is required |

## 6. Demo safety
Use only fictional names, email addresses, mobile numbers and grievance descriptions. Do not enter real personal, medical, financial or other sensitive information. This prototype is not an official government service.
